# Security policy

This document tells which versions get security fixes and how to report a vulnerability.

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem. Use the private vulnerability reporting of GitHub:

1. Open the tab "Security" of this repo.
2. Select "Report a vulnerability".

Include:

- the app version (the tag, for example `v0.1.0`)
- the steps to reproduce the problem
- the result that you expected and the result that you got

The maintainers fix a confirmed problem in a new release. The maintainers name you in the release notes, unless
you ask them not to.
